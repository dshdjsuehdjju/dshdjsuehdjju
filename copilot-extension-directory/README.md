# 拓展集 · Copilot 资源目录

独立的中文优先静态网页，用于浏览 MCP 服务、Skills、Agents 和 Canvas 扩展示例。资源数据保存在 `resources.js`，无需构建步骤、账号、外部字体或第三方运行库；页面不会安装或执行目录中的资源。

## 本地启动

在项目目录运行（需要已安装 Node.js，无需安装 npm 包）：

```text
node server.js
```

然后访问 <http://localhost:4173>。也可以使用其他静态文件服务器提供本目录。

## 在 Copilot App 中打开

仓库包含项目级 Canvas 扩展 `.github/extensions/copilot-resource-directory/`。在此仓库对应的 Copilot 会话中打开「拓展集 · 资源市场」画布，即可在 App 面板浏览同一份目录数据；如果扩展尚未显示，请重新加载扩展或重启该会话。扩展只在 `127.0.0.1` 提供目录页面所需的静态文件，不会自动安装或执行资源。

## 功能

- 按资源类型筛选，按名称/用途/标签搜索，支持排序与清除筛选。
- 详情展示项目介绍、原始来源、通用安装指引、维护状态和信任提示。
- 适配窄屏布局，支持键盘 `/` 聚焦搜索、Escape 关闭详情。
- 外部资源链接指向各项目来源；Canvas 卡片明确标记为本地演示/待核验，不可安装。
